# Kit do Time · Hackathon Fogo Alto

Bem-vindo, brigada! Este repositório já vem com a estrutura pronta. Vocês NÃO começam do zero: começam preenchendo.

## O caminho (não pule etapas)

1. **Preencham a pasta `contexto/`**: cada pessoa é dona de um arquivo:
   - `contexto/01-dor.md` → Voz do Cliente (dono/empresa)
   - `contexto/02-prd.md` → Chef de Produto
   - `contexto/03-negocio.md` → Gerente de Salão (negócios)
   - `contexto/04-wireframe.md` → Empratamento (design)
2. **Coloquem os dados reais na pasta `dados/`** (anonimizados). Leiam `dados/LEIA-ME.md`.
3. **Cada um faz o commit do próprio arquivo.** Seu nome entra na história do projeto.
4. **Só então o Chef de Partida abre o Claude Code** e roda o primeiro prompt (está na `colinha-prompts.md`).

## Regra da casa

**Nada vai pro fogo sem mise en place.** O Claude Code só é acionado com a Caixa de Contexto completa. Quem pular etapa vai construir a coisa errada, bonita e rápida.

## Ritmo

Ciclos de 90 minutos. Todo ciclo do Dia 2 termina com deploy e teste da Voz do Cliente. Melhor simples no ar do que perfeito no notebook.

## Ajuda

- Colinha de prompts por papel: `colinha-prompts.md`
- Mentores circulando: levante a mão (ou o post-it vermelho na mesa)
